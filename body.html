▼ ELI5 — tl;dr
💬 comment
💡 Plain English
Wool is Terminal Delight's Agent Wall grown into an Omarchy plugin: press the flock icon on the bar and a full-screen overlay shows every coding agent on the machine as a card — a sheepish robot face whose colour says how it's doing (white = fine, dark grey = needs you, black = broken), the last prompt it saw, and its token vitals. Click a card and you're looking at that agent's window. It pairs with Herd: Herd is attention (which sheep needs you, from the bar), Wool is presence (the whole flock, on the wall). Done looks like: bar icon → wall → click → focused agent, with zero writes to any terminal.
▼ What Wool is — and the parity line with TD
💬 comment
🧶 Some parity, on purpose
TD's wall binds panes — it can screenshot live buffers, crawl their text, and restyle them, because it lives inside the terminal's render loop. Wool binds sessions — the unit any process outside TD can actually see. That single difference draws the whole parity line, and it matches the graduation test: a feature ports iff its state sits behind an oracle a widget can query and its presentation is compositor-level.

Ports to Wool: agent cards with face + state, transcript-derived prompt snippets, Δ/Σ token counts, the three vitals bars (CTX WINDOW · FATIGUE · RELEVANCE), state filter counts, click-to-focus.

Stays TD's moat (deliberately not ported): live buffer thumbnails, per-pane text crawl, pane restyling ("agents can restyle"), copy chips, the Alt+R reader. Those are the reasons to graduate from the plugin to the terminal — Wool advertising them would erase TD's pitch.

Composes with Herd, never competes: Herd's bar badge answers "who needs me right now" and jumps to the stuck one. Wool's wall answers "what does my whole flock look like". Both may be installed; neither requires the other.

▼ Oracles — where the truth comes from

Reshaped: state now has exactly one oracle — the Crook bus — and Wool detects nothing itself. Building wool-scan as its own detector would have created the fourth parallel state-detector on this machine, the exact pathology the Crook decision record was written to stop.

  • crook state.json — who exists, what state, from which source (self beats herdr), each entry carrying its own stale_after; past it the entry reads as unknown, full stop. Claude sessions self-report via hooks (which also capture the last prompt, so no transcript is read for the card snippet); crook sync-herdr mirrors non-self-reporting agents.
  • terminal-delight agent-vitals — the shipped CLI (verified: batches transcripts, emits JSON) computes the CTX WINDOW / FATIGUE / RELEVANCE trio plus the model·effort chip. Optional enrichment, read only while the wall is open.
  • Transcripts directly — no longer read by Wool at all. Crook carries the transcript path for the vitals CLI; the snippet rides the hook payload. The discovery sweep from the original plan is gone entirely.
💬 comment
⚠️ Unknown is not zero
A card with no vitals (no TD binary, a Codex session, an unreadable transcript) renders absence — a dashed empty track or no track at all — never a zero-length bar. A zero-length bar is a confident wrong number; the snapshot JSON keeps every unmeasured field null, and only the QML renderer decides how null draws.
▼ Architecture — bar widget, overlay, and one scan script

Structure mirrors omarchy-herd exactly: manifest.json (kind bar-widget, id brownfamilysports.wool, category AI), Panel.qml as the entry point, a wool/ directory of helper scripts, tests/run.sh with stub binaries.

  • Bar widget: a flock glyph with up to three counts — white/grey/black tier tallies. hideWhenEmpty default true. Click toggles the wall.
  • The wall: a Quickshell layer-shell surface over the focused monitor's workspace — the toggle-overlay form. Card grid grouped the way TD groups (project dir), state chips, filter counts along the top.
  • wool-scan: one script that merges the three oracles into a single snapshot JSON (herdr snapshot if the socket answers, transcript sweep, vitals per session when the CLI exists). QML renders the snapshot and nothing else — the scan is the only thing that touches disk.
  • Scan gating: wool-scan runs only while the wall is open (plus one cheap tally pass for the bar counts on a slow timer). TD learned this the hard way — the ungated sweep read ~3.5MB/s with the wall closed.
bar click ─→ wall opens ─→ wool-scan (herdr snapshot + transcript sweep + vitals) ─→ snapshot.json ─→ QML cards
card click ─→ herdr agent focus <id>   (herded agent)
          └→ hyprctl dispatch focuswindow address:<addr>   (pid→window fallback)
▼ The flock — card anatomy and state colours

Each card: sheepish robot face (state-keyed), agent program chip (CLAUDE / SHELL / …), project directory, last prompt snippet from the transcript, state chip, Δ latest-turn and Σ total tokens, and the three vitals bars when measured.

💬 comment
🐑 Fleece says the tier, chip says the state
The robot's fleece carries exactly three colours — white = status good (running, healthy idle), dark grey = attention (done, question waiting, unknown/undetected state), black = error (failed, crashed, unreadable). Fine-grained states (RUN · PAUSED · FAIL · DONE · IDLE) live in the chip; the fleece is the squint-from-across-the-room signal. Note "unknown" lands in grey by definition — an undetected state is an attention state, not a good one.

Colour means direction, length means number — the vitals bars keep TD's rule: each bar's ramp is tied to the threshold its verdict acts on, so a bar can't look calm beside a chip that says act.

▼ Face art — the playhouse stays canon

The sheepish robot is authored in agent-playhouse (web/art/robot.svg + props.svg, under CONVENTIONS.md's rules — verb first, then draw), reviewed on /sheet.html, enforced by bun test. Everything downstream is a photograph: playhouse → TD app → web wall, and now → Wool as one more publish target.

Parker generates the sheep variant himself (white/grey/black fleece states); Wool's job is only the receiving end: a publish target with a --check mode, because a stale derived copy once sat unnoticed for months. Wool never edits art.

▼ Tradeoffs — deliberately not done
  • No persistent kiosk mode in v1. Chosen: toggle overlay. A parked-monitor TV mode forfeits the scan gating and needs its own window lifecycle — a clean v2 once the overlay proves the card grid.
  • No PTY writes, no prompting from cards. "Watches agents · never writes to a PTY" stays literally true; herdr agent prompt exists if that line ever moves, but moving it is a doctrine change, not a feature.
  • No buffer thumbnails or text crawl. The moat clause — those require living inside the terminal's render loop, and they are TD's reason to exist.
  • Vitals are an optional enhancement, not a dependency. Wool installs and works on a box with no terminal-delight binary; it just shows fewer numbers, honestly.
  • Claude transcripts only in v1. Codex rollouts have a different schema (TD's #279 found CTX WINDOW reachable but nothing else); Codex sessions appear via herdr presence with null vitals rather than a half-invented schema port.
▼ Risks and gotchas
  • Resolved by the Crook reshape: the original highest risk — wool-scan inheriting every transcript trap as a fourth parallel detector — is gone; state has one oracle and the traps live with TD's already-tested vitals CLI. The residual risk moved: Claude visibility now depends on the crook hooks being installed (they are, machine-global, guarded with || true so a missing binary can never break a session), and a session started before the hooks existed stays invisible until its next event.
  • herdr absent or socket dead: handled — sync-herdr publishes an honest empty mirror and self-reported entries are untouched; covered by tests.
  • Keybind for the wall: Omarchy owns the SUPER map and fcitx5 already stole Ctrl+Shift+U once; v1 binds nothing and relies on the bar click, with a keybind as a user opt-in snippet in the README.
  • Stale derived art: the --check mode is the guard; wire it into tests/run.sh so CI catches it, not a passerby months later.
